# Solopromotora Financiamentos — site institucional

Página única em HTML5, CSS3 e JavaScript puro. Sem frameworks, sem build e sem backend.

## Arquivos

| Arquivo | Uso |
|---|---|
| `index.html` | Página completa (CSS e JS embutidos) |
| `logo.png` | Logo redondo (header e favicon) |
| `logo-rodape.png` | Logotipo "SOLOPROMOTORA." com slogan, para fundo escuro (rodapé) |

Única dependência externa: Google Fonts (Nunito e IBM Plex Mono).

## Rodar localmente

Abra `index.html` no navegador. A geolocalização ("Qual fica mais perto de mim?") só funciona em `https://` ou `localhost`.

## Publicar

Sirva os três arquivos na raiz de qualquer hospedagem estática com HTTPS (GitHub Pages, Netlify, Vercel, etc.).
